# Chica-Lab

A sleek fashion marketing landing page inspired by premium clothing brands. The project focuses on a bold, modern storefront aesthetic with editorial typography, strong CTAs, and clean product showcase sections.

## Preview

Open the `The ChicaLab Site/index.html` file in a browser to view the landing page.

## Tech Stack

- HTML
- CSS
- JavaScript
- Google Fonts
- Font Awesome icons

## Project Highlights

- Stylish hero banner with fashion-focused messaging
- Product showcase gallery sections
- Modern brand styling with bold contrast colors
- Clean promotional offers and sale blocks
- Mobile-friendly responsive layout structure
